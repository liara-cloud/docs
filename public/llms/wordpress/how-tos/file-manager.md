# مدیریت فایل‌های وردپرسی

[Video link](https://media.liara.ir/wordpress/file-management.mp4)

برای مدیریت فایل‌های وردپرس در خود کنسول لیارا، تنها کافیست تا در برنامه وردپرس خود، وارد بخش **فایل‌ها** شوید.  
در این بخش، می‌توانید فایل‌های موجود در مسیر `var/www/html/` را مشاهده کرده و سایر عملیات کار با فایل را انجام دهید.
