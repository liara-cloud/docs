# کار با دیتابیس برنامه وردپرس

[Video link](https://media.liara.ir/wordpress/work-with-db.mp4)

برای کار با دیتابیس برنامه وردپرسی خود، تنها کافیست تا وارد منوی **دیتابیس** شوید. در این صفحه، اطلاعات ورود به دیتابیس برای شما مهیا است.  
دیتابیس مورد استفاده برای برنامه‌های وردپرسی در لیارا، [ماریا دی بی یا MariaDB](https://mariadb.org/) است. 

## استفاده از PHPMyAdmin

[PHPMyAdmin](https://www.phpmyadmin.net/) یک ابزار متن‌باز و تحت وب برای مدیریت دیتابیس MariaDB است. با استفاده از آن می‌توانید بدون نیاز به اجرای مستقیم دستورات خط فرمان، دیتابیس و جدول بسازید، داده‌ها را مشاهده یا ویرایش کنید، کوئری‌های SQL اجرا کنید و از دیتابیس خروجی یا نسخه پشتیبان بگیرید.

برای استفاده از PHPMyAdmin تنها کافیست تا در صفحه **دیتابیس** گزینه **راه‌اندازی PHPMyAdmin** را فعال کنید تا PHPMyAdmin برای شما به مدت ۵ ساعت فعال شود.  
بعد از گذشت ۵ ساعت، این دسترسی، به صورت خودکار، حذف خواهد شد و شما می‌توانید برای دسترسی مجدد به PHPMyAdmin، گزینه آن را فعال کنید.
