# تنظیم میرور در سیستم عامل Manjaro


## سرویس میرور Manjaro لیارا چیست؟

میرور Manjaro لیارا یک نسخه‌ی سریع و داخلی از مخازن رسمی Manjaro Linux است که برای افزایش سرعت، پایداری و دسترس‌پذیری در نصب و به‌روزرسانی پکیج‌ها طراحی شده است.



با استفاده از این میرور، تمام درخواست‌های pacman ابتدا به سرورهای داخلی لیارا ارسال می‌شوند و پکیج‌ها با سرعت بسیار بالاتر، بدون محدودیت‌های CDN خارجی و بدون مواجهه با اختلال‌ها یا تحریم‌های بین‌المللی دریافت می‌شوند.

## تنظیم میرور در سیستم عامل Manjaro

لیارا برای سیستم عامل Manjaro، میرور زیر را ارائه می‌دهد:



```bash
https://linux-mirror.liara.ir/repository/manjaro/
```


برای تنظیم میرور فوق در سیستم عامل Manjaro خود، گام‌های زیر را طی کنید:

۱. تهیه بکاپ از تنظیمات فعلی
قبل از تنظیم میرور لیارا، بهتر است یک بکاپ از تنظیمات فعلی تهیه کنید:

```bash
[ -e /etc/pacman.d/mirrorlist.bak ] || sudo cp /etc/pacman.d/mirrorlist /etc/pacman.d/mirrorlist.bak
```

۲. تنظیم میرور لیارا
برای تنظیم میرور لیارا، دستور زیر را اجرا کنید:

```bash
sudo tee /etc/pacman.d/mirrorlist <<'EOF'
Server = https://linux-mirror.liara.ir/repository/manjaro/stable/$repo/$arch
EOF
```

> عبارت‌های `$repo` و `$arch` را تغییر ندهید و دستور را دقیقاً با همین شکل (با `{`<<'EOF'`}` و تک‌کوتیشن) اجرا کنید. این دو متغیر را خود `pacman` پر می‌کند و اگر شل آن‌ها را جایگزین کند، آدرس نادرست می‌شود.

۳. آپدیت سیستم
اکنون دستور زیر را اجرا کنید تا فهرست مخازن به‌روزرسانی شود:

```bash
sudo pacman -Syyu
```



با انجام کارهای فوق، میرور لیارا در سیستم عامل Manjaro شما تنظیم خواهد شد و درخواست‌های آپدیت یا دانلود پکیج به این میرور ارسال می‌شود.

## بازگشت به تنظیمات قبلی

اگر خواستید تنظیمات قبلی را برگردانید، دستورات زیر را اجرا کنید:


```bash
sudo cp /etc/pacman.d/mirrorlist.bak /etc/pacman.d/mirrorlist
sudo pacman -Syy
```


## نکات

- آدرس میرور را باید به‌صورت `.../repository/manjaro/stable/$repo/$arch` در `Server` بنویسید. اگر فقط آدرس پایه (`.../repository/manjaro/`) را بدهید، `pacman` فایل‌های دیتابیس را پیدا نمی‌کند و خطای 404 می‌گیرد.
- بکاپ فقط در اولین اجرا ساخته می‌شود. اگر دستور گام ۱ را دوباره اجرا کنید، بکاپ اصلی بازنویسی نمی‌شود.
