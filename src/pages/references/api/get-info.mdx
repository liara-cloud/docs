# دریافت اطلاعات جامع کاربر و کنسول با API 
<hr className="mb-2" />

یکی از endpointهایی که <Important>api.liara.ir</Important> ارائه می‌دهد، <Important>me/</Important> است. این endpoint شامل اطلاعات زیر است: 

<div className="h-2" />
<ul>
  <li>اطلاعات خود کاربر (مانند نام، ایمیل، شماره موبایل و نوع حساب کاربری)</li>
  <li>اطلاعات Object Storage کاربر</li>
  <li>اطلاعات امنیتی حساب کاربری</li>
  <li>اطلاعات مرتبط با سطح کاربری فعلی کاربر</li>
  <li>امکانات فعال حساب کاربری (مانند شبکه خصوصی)</li>

  <div className="h-4" />

  <li>نسخه‌های قابل ارائه دیتابیس‌های لیارا</li>
  <li>نسخه‌های پیش‌فرض دیتابیس‌های لیارا</li>

  <div className="h-4" />

  <li>پلن‌های PaaS لیارا</li>
  <li>پلن‌های سرویس ایمیل لیارا</li>
  <li>پلن‌های دیتابیس لیارا</li>
  <li>پلن‌های Object Storage لیارا</li>

  <div className="h-4" />

  <li>بسته امکانات PaaS</li>
  <li>بسته امکانات دیتابیس‌ها</li>

  <div className="h-4" />

  <li>اطلاعات بسته‌های سطح کاربری</li>

</ul>
<div className="h-2" />

<div className="h-2" />
<ul>

  <div className="h-1" />
  <li><Important>databaseVersions</Important>: نسخه‌های قابل ارائه برای هر نوع دیتابیس</li>
  <div className="h-1" />
  <li><Important>defaultDatabaseVersions</Important>: نسخه پیش‌فرض هر نوع دیتابیس</li>
  <div className="h-1" />
  <li><Important>plans</Important>: پلن‌های محصولات لیارا و بسته‌های امکانات آن‌ها</li>
</ul>

  <div className="h-1" />
  <li><Important>accountType</Important>: نوع حساب کاربری، مانند <Important>REAL_PERSON</Important> برای حساب‌های حقیقی</li>
  <div className="h-1" />
  <li><Important>isTeam</Important>: مشخص می‌کند که آیا این حساب یک تیم است یا خیر</li>
  <div className="h-1" />
  <li><Important>invoiceIssuingEnabled</Important>: مشخص می‌کند که آیا صدور فاکتور برای حساب فعال است یا خیر</li>
  <div className="h-1" />
  <li><Important>minCreditAmount</Important>: حداقل مبلغ اعتبار برای اعلان در حساب کاربری. اگر <Important>isManualMinCredit</Important> برابر <Important>true</Important> باشد، این مقدار به‌صورت دستی تعیین شده است</li>
  <div className="h-1" />
  <li><Important>remainingFreeCredit</Important>: میزان اعتبار رایگان باقی‌مانده</li>
  <div className="h-1" />
  <li><Important>hasSucceedPayment</Important>: مشخص می‌کند که آیا حساب کاربری تاکنون پرداخت موفقی داشته است یا خیر</li>
  <div className="h-1" />
  <li><Important>hasPassword</Important> و <Important>twoFA</Important>: وضعیت تعیین رمز عبور و فعال بودن احراز هویت دو مرحله‌ای</li>
  <div className="h-1" />
  <li><Important>storage</Important>: اطلاعات Object Storage شامل <Important>namespace</Important>، وضعیت، شناسه پلن و کلیدهای دسترسی</li>
  <div className="h-1" />
  <li><Important>privateNetworkFeature</Important>: مشخص می‌کند که آیا امکان استفاده از شبکه خصوصی برای حساب فعال است یا خیر</li>
  <div className="h-1" />
  <li><Important>currentSubscriptionPlan</Important>: اطلاعات سطح کاربری فعلی، شامل شناسه پلن (<Important>subscriptionPlanID</Important>)، تاریخ انقضا و ...</li>
  <div className="h-1" />
  <li><Important>gitRepositoryIntegrations</Important> و <Important>gitProviderIntegrations</Important>: اتصال‌های حساب کاربری به repositoryها و سرویس‌های مبتنی بر Git</li>
</ul>
