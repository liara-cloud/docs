# دریافت اطلاعات جامع کاربر و کنسول با API 
<hr className="mb-2" />

یکی از endpointهایی که <Important>api.liara.ir</Important> ارائه می‌دهد، <Important>me/</Important> است. این endpoint شامل اطلاعات زیر است: 

<div className="h-2" />
<ul>
  <li>اطلاعات خود کاربر (مانند نام، ایمیل، شماره موبایل و نوع حساب کاربری)</li>
  <li>اطلاعات Object Storage کاربر</li>
  <li>اطلاعات امنیتی حساب کاربری (مانند وضعیت رمز عبور و تایید ایمیل و موبایل)</li>
  <li>اطلاعات مرتبط با سطح کاربری فعلی کاربر</li>
  <li>امکانات فعال حساب کاربری (مانند شبکه خصوصی)</li>

  <div className="h-4" />

  <li>نسخه‌های قابل ارائه دیتابیس‌های لیارا</li>
  <li>نسخه‌های پیش‌فرض دیتابیس‌های لیارا</li>

  <div className="h-4" />

  <li>پلن‌های PaaS لیارا</li>
  <li>پلن‌های سرویس ایمیل لیارا</li>
  <li>پلن‌های دیتابیس لیارا</li>
  <li>پلن‌های Object Storage لیارا</li>

  <div className="h-4" />

  <li>بسته امکانات PaaS</li>
  <li>بسته امکانات دیتابیس‌ها</li>

  <div className="h-4" />

  <li>اطلاعات بسته‌های سطح کاربری</li>

</ul>
<div className="h-2" />

برخی از اطلاعات حساب کاربری، مانند سطح کاربری فعلی، وضعیت احراز هویت دو مرحله‌ای، اعتبار رایگان، اتصال‌های Git و اطلاعات UTM، دیگر در پاسخ <Important>me/</Important> ارائه نمی‌شوند و باید آن‌ها را از <a href="#sub-endpoints" className="text-[#2196f3]">endpointهای جداگانه <Important>/me/*</Important></a> دریافت کنید.

<Section id="response-structure" title="ساختار پاسخ" />

پاسخ این endpoint یک آبجکت JSON است که از چند بخش اصلی تشکیل شده است. در فهرست زیر می‌توانید این بخش‌ها را ببینید:

<div className="h-2" />
<ul>
  <li><Important>user</Important>اطلاعات حساب کاربری</li>
  <div className="h-1" />
  <li><Important>team</Important>: اطلاعات تیم، نقش و دسترسی‌های عضو تیم (فقط زمانی که درخواست در حالت تیمی ارسال شود)</li>
  <div className="h-1" />
  <li><Important>databaseVersions</Important>: نسخه‌های قابل ارائه برای هر نوع دیتابیس</li>
  <div className="h-1" />
  <li><Important>defaultDatabaseVersions</Important>: نسخه پیش‌فرض هر نوع دیتابیس</li>
  <div className="h-1" />
  <li><Important>plans</Important>: پلن‌های محصولات لیارا و بسته‌های امکانات آن‌ها</li>
</ul>
<div className="h-2" />

در ادامه، مهم‌ترین فیلدهای بخش <Important>user</Important> توضیح داده شده است:

<div className="h-2" />
<ul>
  <li><Important>fullname</Important> و <Important>nationalCode</Important>: نام و کد ملی ثبت‌شده برای حساب کاربری</li>
  <div className="h-1" />
  <li><Important>email</Important> و <Important>phone</Important>: ایمیل و شماره موبایل حساب کاربری. زمان تایید هر کدام در <Important>emailVerifiedAt</Important> و <Important>phoneVerifiedAt</Important> مشخص است</li>
  <div className="h-1" />
  <li><Important>isVerified</Important>: وضعیت احراز هویت حساب کاربری</li>
  <div className="h-1" />
  <li><Important>accountType</Important>: نوع حساب کاربری، مانند <Important>REAL_PERSON</Important> برای حساب‌های حقیقی</li>
  <div className="h-1" />
  <li><Important>isTeam</Important>: مشخص می‌کند که آیا این حساب یک تیم است یا خیر</li>
  <div className="h-1" />
  <li><Important>invoiceIssuingEnabled</Important>: مشخص می‌کند که آیا صدور فاکتور برای حساب فعال است یا خیر</li>
  <div className="h-1" />
  <li><Important>minCreditAmount</Important>: حداقل مبلغ اعتبار برای اعلان در حساب کاربری. اگر <Important>isManualMinCredit</Important> برابر <Important>true</Important> باشد، این مقدار به‌صورت دستی تعیین شده است</li>
  <div className="h-1" />
  <li><Important>hasSucceedPayment</Important>: مشخص می‌کند که آیا حساب کاربری تاکنون پرداخت موفقی داشته است یا خیر</li>
  <div className="h-1" />
  <li><Important>hasPassword</Important>: مشخص می‌کند که آیا برای حساب کاربری رمز عبور تعیین شده است یا خیر</li>
  <div className="h-1" />
  <li><Important>storage</Important>: اطلاعات Object Storage شامل <Important>namespace</Important>، وضعیت، شناسه پلن و کلیدهای دسترسی</li>
  <div className="h-1" />
  <li><Important>privateNetworkFeature</Important>: مشخص می‌کند که آیا امکان استفاده از شبکه خصوصی برای حساب فعال است یا خیر</li>
</ul>

<Section id="sub-endpoints" title="endpointهای جداگانه اطلاعات حساب کاربری" />

علاوه بر <Important>me/</Important>، endpointهای زیر برای دریافت بخش‌های مشخصی از اطلاعات حساب کاربری ارائه شده‌اند. همه این endpointها با متد <Important>GET</Important> فراخوانی می‌شوند و در حالت تیمی، اطلاعات تیم را برمی‌گردانند:

<div className="h-2" />
<ul>
  <li><Important>me/subscription/</Important>: اطلاعات سطح کاربری فعلی</li>
  <div className="h-1" />
  <li><Important>me/two-fa/</Important>: وضعیت احراز هویت دو مرحله‌ای</li>
  <div className="h-1" />
  <li><Important>me/free-credit/</Important>: میزان اعتبار رایگان باقی‌مانده</li>
  <div className="h-1" />
  <li><Important>me/git-integrations/</Important>: اتصال‌های حساب کاربری به سرویس‌ها و repositoryهای Github</li>
  <div className="h-1" />
  <li><Important>me/utm/</Important>: اطلاعات کمپین (UTM) که حساب کاربری از طریق آن عضو شده است</li>
</ul>
