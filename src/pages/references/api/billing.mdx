# دریافت اطلاعات مالی با API 
<hr className="mb-2" />

برای دریافت اطلاعات مالی می‌توانید از endpoint زیر استفاده کنید:

<div className="h-4" />
<div dir="ltr">
<Highlight className='bash'>
{`https://api.liara.ir/v1/billing`}
</Highlight>
</div>
<div className="h-2" />

این endpoint شامل اطلاعات زیر است:


<div className="h-2" />
<ul>
  <li>میزان اعتبار (به تومان)</li>
  <li>نوع اکانت (فرد حقیقی یا حقوقی)</li>
  <li>اعتبار وقتی به کمتر از این عدد برسه، اطلاع‌رسانی ارسال می‌شه</li>
  <li>فعال بودن یا نبودن هشدار حداقل اعتبار تنظیم شده توسط کاربر (در غیر این‌صورت، با تصمیم سیستم)</li>
  <li>زمان آخرین باری که سیستم درباره کمبود اعتبار اطلاع‌رسانی کرده</li>
</ul>
<div className="h-2" />

<Section id="example" title="نمونه ارسال درخواست" />

<div dir="ltr">
<Highlight className='bash'>
{`curl --request GET \\
  --url https://api.liara.ir/v1/billing \\
  --header "Authorization: Bearer TOKEN"`}
</Highlight>
</div>
<div className="h-2" />

در عبارت فوق، بایستی به جای <Important>TOKEN</Important>، <a href="/references/api/about/#api-access-key" className="text-[#2196f3]">کلید API حساب کاربری خود</a> را وارد کنید.
