# تنظیم میرور در سیستم عامل Debian
<hr className="mb-2" />

لیارا برای سیستم عامل Debian، میرورهای زیر را ارائه می‌دهد:

<div dir='ltr'>

برای تنظیم میرورهای فوق در سیستم عامل Debian خود، گام‌های زیر را طی کنید:

<Step  steps={[
    {
        step: "۱",
            content: (
                <>
                    <h3>تهیه بکاپ و خالی کردن sources.list</h3>
                    <p>قبل از تنظیم میرورهای لیارا، دستور زیر از فایل‌های <Important>sources.list</Important> و <Important>debian.sources</Important> بکاپ می‌گیرد (در پوشه‌ی <Important>/etc/apt/backup</Important>) و سپس محتوای <Important>/etc/apt/sources.list</Important> را پاک می‌کند تا مخازن قدیمی با میرور لیارا تداخل نداشته باشند:</p>
                    <div className="h-2" />
                    <div dir='ltr'>
                        <Highlight className="bash">
                            {`sudo mkdir -p /etc/apt/backup
for f in /etc/apt/sources.list /etc/apt/sources.list.d/debian.sources; do
  b="/etc/apt/backup/$(basename "$f")"
  [ -f "$f" ] && [ ! -e "$b" ] && sudo cp "$f" "$b"
done
sudo truncate -s 0 /etc/apt/sources.list`}
                        </Highlight>
                    </div>
                </>
            )
    },
    {
        step: "۲",
            content: (
                <>
                    <h3>تنظیم میرور لیارا</h3>
                    <p>دستور زیر نام نسخه‌ی سیستم عامل شما (مثل <Important>bookworm</Important>) را خودکار تشخیص می‌دهد و فایل <Important>debian.sources</Important> را با میرورهای لیارا می‌سازد:</p>
                    <div className="h-2" />
                    <div dir='ltr'>
                        <Highlight className="bash">
                            {`CODENAME=$(. /etc/os-release && echo "$VERSION_CODENAME")
sudo tee /etc/apt/sources.list.d/debian.sources <<EOF
Types: deb deb-src

Suites: $CODENAME $CODENAME-updates
Components: main non-free-firmware

Types: deb deb-src
URIs: http://linux-mirror.liara.ir/repository/debian-security
Suites: $CODENAME-security
Components: main non-free-firmware
Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg
EOF`}
                        </Highlight>
                    </div>

با انجام کارهای فوق، میرورهای لیارا در سیستم عامل شما تنظیم خواهند شد و درخواست‌های آپدیت یا دانلود پکیج به این میرورها ارسال خواهند شد.

<Section id='unset-mirrors' title='بازگشت به تنظیمات قبلی' />

اگر خواستید تنظیمات قبلی را برگردانید، دستورات زیر را اجرا کنید:

<div className="h-2" />
<div dir='ltr'>
    <Highlight className="bash">
        {`sudo cp /etc/apt/backup/sources.list /etc/apt/sources.list
if [ -f /etc/apt/backup/debian.sources ]; then
  sudo cp /etc/apt/backup/debian.sources /etc/apt/sources.list.d/debian.sources
else
  sudo rm -f /etc/apt/sources.list.d/debian.sources
fi
sudo apt update`}
    </Highlight>
</div>

<ul>
<li>در گام ۱ محتوای <Important>/etc/apt/sources.list</Important> به‌طور کامل پاک می‌شود. اگر مخازن دیگری (غیر از Debian) در این فایل اضافه کرده بودید، آن‌ها را از فایل بکاپ به یک فایل جدید در <Important>/etc/apt/sources.list.d/</Important> منتقل کنید.</li>
<li>بکاپ‌ها فقط در اولین اجرا ساخته می‌شوند. اگر دستور گام ۱ را دوباره اجرا کنید، بکاپ اصلی بازنویسی نمی‌شود.</li>
