# کار با دیتابیس برنامه وردپرس
<hr className="mb-2" />

<video
  src="https://media.liara.ir/wordpress/work-with-db.mp4"
  controls="controls"

<div className="h-4" />

برای کار با دیتابیس برنامه وردپرسی خود، تنها کافیست تا وارد منوی <b>دیتابیس</b> شوید. در این صفحه، اطلاعات ورود به دیتابیس برای شما مهیا است. 
دیتابیس مورد استفاده برای برنامه‌های وردپرسی در لیارا، <a href="https://mariadb.org/" className="text-[#2196f3]">ماریا دی بی یا MariaDB</a> است. 


<Section id='use-phpmyadmin' title='استفاده از PHPMyAdmin' />

<a href="https://www.phpmyadmin.net/" className="text-[#2196f3]">PHPMyAdmin</a> یک ابزار متن‌باز و تحت وب برای مدیریت دیتابیس MariaDB است. با استفاده از آن می‌توانید بدون نیاز به اجرای مستقیم دستورات خط فرمان، دیتابیس و جدول بسازید، داده‌ها را مشاهده یا ویرایش کنید، کوئری‌های SQL اجرا کنید و از دیتابیس خروجی یا نسخه پشتیبان بگیرید.

<div className="h-4" />


برای استفاده از PHPMyAdmin تنها کافیست تا در صفحه <b>دیتابیس</b> گزینه <b>راه‌اندازی PHPMyAdmin</b> را فعال کنید تا PHPMyAdmin برای شما به مدت ۵ ساعت فعال شود. 
بعد از گذشت ۵ ساعت، این دسترسی، به صورت خودکار، حذف خواهد شد و شما می‌توانید برای دسترسی مجدد به PHPMyAdmin، گزینه آن را فعال کنید.
