# اتصال به دیتابیس ClickHouse در برنامه‌های NextJS
<hr className="mb-2" />

روش‌ها و کتابخانه‌های مختلفی برای اتصال به ClickHouse در NextJS وجود دارد. یکی از این راه‌ها، استفاده از پکیج <Important>clickhouse</Important> است که در ابتدا، با اجرای دستور زیر، باید آن را نصب کنید:


<div className="h-2" />
<div dir='ltr'>
    <Highlight className="bash">
        {`npm install @clickhouse/client`}
    </Highlight>
</div>
<div className="h-2" />


پس از آن، کافیست تا 
اطلاعات مربوط به دیتابیس خود را 
به متغیرهای محیطی برنامه خود، اضافه کنید؛ به عنوان مثال:

<div className="h-2" />
<div dir='ltr'>
    <Highlight className="bash">
        {`CLICKHOUSE_HOST=http://rainier.liara.cloud:33273
CLICKHOUSE_USER=root
CLICKHOUSE_PASSWORD=x4y2LJvdFyG5wVO87VbXDrpg
NEXT_PUBLIC_APP_URL=http://localhost:3000 # replace it on production`}
    </Highlight>
</div>
<div className="h-2" />

اکنون، می‌توانید متغیرهای محیطی را در برنامه خود خوانده و به دیتابیس متصل شوید؛ برای ساخت کلاینت ClickHouse، کافیست در مسیر <Important>lib/clickhouse.ts</Important>، قطعه کد زیر را قرار دهید:


<div className="h-2" />
<div dir='ltr'>
    <Highlight className="js">
        {`import { createClient } from '@clickhouse/client';

export const clickhouse = createClient({
      host: process.env.CLICKHOUSE_HOST!,
      username: process.env.CLICKHOUSE_USER!,
      password: process.env.CLICKHOUSE_PASSWORD!,
      max_open_connections: 10,
      request_timeout: 10000,
});`}
    </Highlight>
</div>
<div className="h-2" />

اکنون، برای ساخت API Route تنها کافیست تا در مسیر <Important>app/api/clickhouse/route.ts</Important> قطعه کد زیر را قرار دهید: 


<div className="h-2" />
<div dir='ltr'>
    <Highlight className="js">
        {`import { NextResponse } from 'next/server';
import { clickhouse } from '@/lib/clickhouse';

export async function GET() {
  try {
    await clickhouse.query({
      query: 'SELECT 1',
      format: 'JSONEachRow',
    });

    return NextResponse.json({
      success: true,
      message: 'ClickHouse connection successful',
    });
  } catch (error) {
    return NextResponse.json(
      {
        success: false,
        message: 'ClickHouse connection failed',
      },
      { status: 500 }
    );
  }
}`}
    </Highlight>
</div>
<div className="h-2" />

در نهایت، کافیست تا در مسیر <Important>app/clickhouse-test/page.tsx</Important>، قطعه کد زیر را قرار دهید: 


<div className="h-2" />
<div dir='ltr'>
    <Highlight className="js">
        {`export default async function ClickHouseTestPage() {
  const res = await fetch(
    \`${process.env.NEXT_PUBLIC_APP_URL}/api/clickhouse\`,
    {
      cache: 'no-store',
    }
  );

  const data = await res.json();

  return (
    <main>
      <h1>ClickHouse Status</h1>

      <pre>
        {JSON.stringify(data, null, 2)}
      </pre>
    </main>
  );
}`}
    </Highlight>
</div>
<div className="h-2" />

تمامی کارها انجام شده است و اکنون، می‌توانید در مسیر <Important>clickhouse-test/</Important> در مرورگر، تست اتصال به دیتابیس ClickHouse را بررسی کنید.
